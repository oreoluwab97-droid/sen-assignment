# Hello World Python Program

A simple Python program that displays "Hello World" to the console.

## Description

This project contains a basic Python script that demonstrates the classic "Hello World" program - typically the first program written when learning a new programming language.

## Prerequisites

- Python 3.x installed on your system

To check if Python is installed, run:
```bash
python --version
```
or
```bash
python3 --version
```

## Installation

1. Clone this repository:
```bash
git clone https://github.com/oreoluwab97-droid/sen-assignment.git
```

2. Navigate to the project directory:
```bash
cd sen-assignment
```

## Usage

Run the program using Python:

```bash
python hello_world.py
```

or

```bash
python3 hello_world.py
```

## Expected Output

```
Hello World
```
